Map Icons - Remastered pack for Conjunction Map Framework
Version 1.0.0

Brings Map Icons - Remastered's world map icons to CMF's map. The 138 icon pictures
and seven flat region emblems are by kandy422, used with permission. The pictures
show with or without Map Icons installed.

Map Icons - Remastered: https://www.nexusmods.com/witcher3/mods/14490
kandy422: https://www.nexusmods.com/profile/kandy422

REQUIREMENTS
Use Conjunction Map Framework 1.5.0 or later for everything in this pack.
On CMF 1.3.0 to 1.4.x, level badges and your own map pins keep the game's look.
Below CMF 1.3.0, the region emblems also keep the game's look.

INSTALL
Extract this package's Mods folder into your The Witcher 3 game folder, or install
it with a mod manager. It adds Mods\modCMFAdapterMapIconsRemastered.
Keep only one version of this pack installed. No Script Merger is needed.

PICK THE PICTURES
The icons show by themselves. For the region emblems, and wherever another map
mod or icon pack changes the same icons, go to Options > Mods > Conjunction Map
Framework and put Map Icons Remastered first on the Mod order page. You can also
pick it for Region crests and markers or for single icon groups instead.

MINIMAP
Map Icons' own minimap keeps working; without Map Icons, the optional CMF Minimap
Add-on can show these icons on the minimap.

REMOVE
Remove Mods\modCMFAdapterMapIconsRemastered to remove this pack. Remove the pack
before removing CMF; it needs CMF to load. The pack writes nothing into saves.
