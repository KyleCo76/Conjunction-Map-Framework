# Going back to the 1.0.0 adapters

Delete `Mods\modCMFAdapterGwentPlayersMap` or `Mods\modCMFAdapterWitcherGearMap`, then install the same adapter from CMF 1.0.0. The 1.0.0 adapters show CMF's placeholder pictures instead of the author's art; everything else is the same.

The adapters write nothing into saves. Remove an adapter before removing CMF or the mod it adapts, as with 1.0.0; otherwise the game stops at the script compile screen until the adapter is removed too.
