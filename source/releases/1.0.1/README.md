# CMF adapters 1.0.1

Two adapter updates for Conjunction Map Framework 1.0.0. CMF itself and every other adapter stay at 1.0.0.

| ZIP | What it is | Install |
| --- | --- | --- |
| `modCMFAdapterGwentPlayersMap-1.0.1.zip` | Gwent Players Map adapter, now with the card art of Gwent Players Map's author | With CMF 1.0.0 and Gwent Players Map 1.0.9 |
| `modCMFAdapterWitcherGearMap-1.0.1.zip` | Witcher Gear Map adapter, now with the gear art of Witcher Upgrade Gear Map's author, each school in its own colour | With CMF 1.0.0 and Witcher Upgrade Gear Map 1.0.1 |

## What changed since 1.0.0

- Both adapters show the art of MateusAnd, the author of Gwent Players Map and Witcher Upgrade Gear Map, shipped with their permission and credited in each adapter's README. It replaces CMF's own placeholder pictures.
- Witcher Gear Map: one picture for each marker type, so the "School colour" icon styles show the author's own colours; the adapter no longer colours the pictures itself.
- Thanks to MateusAnd for testing the adapters on Linux with Steam and Proton.

Nothing else changed: the same marker types, tabs, legend rows and behaviour as 1.0.0.

## Install

Install over the 1.0.0 adapter: delete `Mods\modCMFAdapterGwentPlayersMap` or `Mods\modCMFAdapterWitcherGearMap` first, or let your mod manager replace it. No Script Merger is needed.

`SHA256SUMS` covers the ZIPs and this file; `manifest.json` lists every file with its SHA-256.
