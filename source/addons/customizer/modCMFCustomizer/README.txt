CMF Customizer 1.0.0

An optional add-on for Conjunction Map Framework (CMF). It adds one Options page (Options > Mods > CMF Customizer)
where you set pin sizes, how icon labels show and which pin groups hide.

Needs CMF with API 19 (the Player setting level and the size multipliers). With an older CMF the add-on sends nothing at all.

Every row starts at Off. A row at Off sends nothing, so CMF's Mod order decides that setting exactly as it does
without this add-on. Size rows are multipliers of the size your map mods give (Standardize icon sizes first makes every icon the most common size, then the multiplier scales it). Other rows you set win over the map mods for that setting, whatever your Mod order says. CMF's own
choice rows, if you set them, still come first (for example Vanilla keeps the game's own look).

Rows: Pin size, Standardize icon sizes, Quest marker size, Undiscovered place (?) size, Selected pin growth, Show icon labels (Always, Never,
On hover), and for each pin group (General, Quests, Exploration, NPCs, Buffs) Game default,
Hide when zoomed far out, Hide when zoomed out or Always hide. Changes apply the next time you open the map.

Install: copy the Mods folder and the bin folder into your game folder.
